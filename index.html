常见问题

你可能想问你可能想问

问

没找到答案？在 GitHub 提问

  1. 01需要会写代码、自带模型吗？

    不用会写代码：说清楚你想要什么，Agent 会拆计划、写脚本、搭场景，你随时纠正。模型要自己接入一种：自带 API Key（OpenAI 兼容）、用 ChatGPT 登录的 Codex，或你自己部署的云服务。

  2. 02支持哪些系统？

    只支持 Windows 10 (1809+) 和 Windows 11，x64，暂时没有 macOS 和 Linux 版本。安装包还没有代码签名，SmartScreen 可能会拦一下：点更多信息，再点仍要运行；运行前可以先核对 SHA-256。新版本需要手动下载覆盖安装，项目和设置都会保留。

  3. 03AI 做出来的游戏，质量有保证吗？

    没有保证。结果取决于你接入的模型，同一个任务换个模型、换个时候，都可能差得很远。自动检查和试玩断言通过，只说明游戏跑得起来、符合规格，不代表好玩——最后一关，还得你亲自玩。

  4. 040.1.0 还有哪些限制？

    Design 模式目前只复刻 2D 画面，3D 场景请交给 Agent 或 UltraPlan。应用界面只有简体中文。还没有面向发布的一键导出：游戏在工作台里运行和试玩，场景、脚本和素材都是工作区里的普通文件。

  5. 05数据存在哪里？是开源的吗？

    都在你自己的电脑上，默认放在 %APPDATA%\RurixForge\data，API Key 由 Windows DPAPI 加密保存。RurixForge 以 Apache-2.0 许可证开源，源码在 GitHub 上。
