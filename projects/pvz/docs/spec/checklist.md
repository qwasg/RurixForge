## 跨系统与工程约束
- [ ] 阳光：天降、植物生产、点击收集、HUD 计数
- [ ] 种子卡：选取态、价格校验、冷却遮罩、不可用反馈
- [ ] 种植：屏幕到视口到网格换算、占用/泳池睡莲/屋顶花盆校验
- [ ] 铲子：进入铲子模式、移除植物、正确清空占用
- [ ] 战斗：直线/抛射、Trigger AABB、啃食、HP、死亡、减速/冰冻计时
- [ ] 小推车：每行一辆、触发后整行清除、spent 后不可重复
- [ ] 判负：僵尸越过判负线进入 defeat
- [ ] 关卡流：选关→选卡→战斗→奖励→解锁下一关
- [ ] 进度：宿主/编辑器写入 `Content/save.json`；运行时不假称能写文件
- [ ] 坐标：所有玩法实体 XY、z=0；相机 +Z 朝 -Z、正交
- [ ] 层级：背景0、草坪1、植物2、子弹3、僵尸4、HUD10
- [ ] 每张节点图先 `graph_validate`；每个 `.rx` 先 `rx_check`
- [ ] PIE：`play_enter`/暂停/步进/退出，事件环无未处置 `logic.unsupported` 与 `anim.warn`
- [ ] 无音频管线：BGM/音效明确跳过，不作为通过条件
