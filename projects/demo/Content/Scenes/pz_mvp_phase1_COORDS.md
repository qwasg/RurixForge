# PZ MVP Phase 1 — 草坪与种植格坐标约定

- 世界轴：`+X` 向右（豌豆飞行方向），`-X` 向左（僵尸行进方向），`+Y` 向上，`Z` 表示草坪行。
- 草坪规格：5 行 × 9 列；行、列均从 1 开始编号。
- 格心公式：
  - `x(col) = -6 + 2 × (col - 1)`
  - `z(row) = 4 - 2 × (row - 1)`
  - 种植格中心：`[x(col), 0, z(row)]`
- 命名：`PZ_Cell_R{row}C{col}`。
- 第一阶段输入契约：`plant_r3c3 = 1`，种植到 `R3C3 = [-2, 0, 0]`；植物视觉中心使用 `[-2, 0.65, 0]`。
- 房屋位于草坪左侧；判负线为 `x = -8`（实体 `PZ_LoseLine_X-8`）。
- 普通僵尸入口为 `x = 12`，按对应行的 `z` 进入；第一阶段示范僵尸位于 R3（`z = 0`）。
- 第一阶段示例：`R1C1=[-6,0,4]`、`R1C9=[10,0,4]`、`R3C3=[-2,0,0]`、`R5C9=[10,0,-4]`。

本文件只描述第一阶段 MVP，不包含第二阶段规则。
