## 真实媒体链路

两位角色均由项目内部 Codex 模式 agent 完成真实 MiniMax 图生视频调用。最终各有 32 张不同的透明视频帧，公共裁切框、脚底/投影锚点一致。原视频、供应商任务号、Codex 会话与运行轨迹保存在 `SourceMedia/` 和 `pipeline/`。

GPT 第一版翼尖触边后，使用内置 image_gen 调整参考图边距，并在同一个项目 Codex 会话重做视频。最终 158 个原视频帧全部通过四边至少 10 像素留白检测，实际最小留白 98 像素。最终证据为 `pipeline/evidence.json`（qualityRevision=2）。

主代理独立重新计算源图、视频、图集 SHA256，全数匹配回执，见 `game/media-integrity-audit.json`。
