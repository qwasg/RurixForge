## 原生 CPU

[CPU 汇总](cpu-acceptance.json)记录六组实际 DLL 场景全部通过，共 **42 条检查与数值记录**。通过 `cs5_reset/input/get/frame` 执行普通游戏指令，没有注入余额、生命、敌人、地图或战役解锁；每组使用新进程与临时存档目录。

- `abi`：ABI、容量、空指针和非法绑定的拒绝。曾发现非法 binding 先推进 0.25 秒再返回失败，已改为整批验证后才推进；[修复前证据](cpu-abi-before-fix.json)和[修复后证据](cpu-abi-results.json)均保留。
- `lifecycle`：落地/工作帧、暂停、完整 2 秒摧毁与 2.5 秒残骸、槽位复用、24 个 ghost 满载等待、12 个 alpha FX 上限、零 dt 重复发布。
- `economy`：真实矿点收入、风电、显卡供电、断电停工/恢复、研究扣费，以及算力线仅锁端点、断电不解除物理驻守、拆线释放移动。
- `battle`：成功攻击后工作帧推进、断供停工、敌人真实造成伤害、单位阵亡、维修扣费及败局核心完整尾段；胜败后经济冻结，视觉时钟可继续并响应暂停。
- `walls`：12 片墙实际闭合形成充能区域、自动充盾开关、拆墙事件与区域开放。
- `campaign`：通过正常收入等待、购买、研究、升级和放波指令完成三关十二波。三关实际记录 149/201/289 次攻击，Boss 改变 21/22/27 格地形，原生战役依次解锁第二、第三关。

另有 4 个 Rust 定向契约测试通过：native ABI、Sprite schema 与 CPU 图集解析/稳定纹理顺序。后续动画索引优化的 [5 个 AnimSystem 回归](anim-index-tests.log)全部通过。CPU 图集解析测试使用临时测试工程，不作为最终游戏画面证据。详细复现方式见 [CPU 说明](CPU-ACCEPTANCE.md)。

## 真实候选包与 GPU

两轮使用候选包自带 Node、原生引擎及预编译 DLL，禁用编译器；候选包被独立复制到临时目录，用户旧实例、旧包和存档未改动。设备为 **NVIDIA GeForce RTX 5060 Laptop GPU**，画面为 **1280×720 原生 RGBA**，WebSocket 请求上限 60 FPS，验收门槛保持 **30 FPS**。

- 普通模式 `--off`：[完整报告](portable-runs/2026-09-09T07-30-21-319Z-off/portable-acceptance.json)。实测 **54.75 FPS**，459 帧/8.3832 秒，16 项检查通过，7 张 PNG 保存。
- 粒子模式 `--on`：[完整报告](portable-runs/2026-09-09T07-32-16-222Z-on/portable-acceptance.json)。实测 **54.72 FPS**，456 帧/8.3337 秒，16 项检查通过，7 张 PNG 保存。

FPS 窗口为实际单波战斗，记录中有 8–9 个活动敌人及约 20–23 个 draw；它不代表最大单位规模或所有电脑的性能。两轮均确认无渲染降级、mesh fallback、截断或原生/流错误；三次 WebSocket 主动关闭均为 `wasClean: true`。测试结束后自建进程与临时运行目录均已清理。

检查包括完整 C4+C5 协议、144 个静态 Web 文件与 10 个字面资源引用、真实资源与供电、研究、AI 驻守和移动、软件工作帧、WS 买卡及重连不重购、核心真实败局与完整残骸尾段。`campaign-progress` 先与新原生场景解锁值核对，之后在 `play_exit` 后测试隔离存档文件解析；后者明确属于文件解析测试，不宣称由该轮渲染测试挣得战役进度。

曾测得未优化独显引擎 27.81 FPS，低于门槛并如实保留失败报告。定位后将动画阶段的重复线性实体查找改为 Sprite 索引遍历，并优化编译引擎；没有减少画面尺寸、替换素材或降低 FPS 阈值。[最终两模式汇总](portable-acceptance-final.json)记录实际配置与引擎身份。复现步骤见 [独立包说明](PORTABLE-ACCEPTANCE.md)。

只枚举本次自建进程的模块：引擎实际加载的 `VCRUNTIME140.dll`、`VCRUNTIME140_1.dll` 和 `MSVCP140.dll` 全部来自隔离包内 `bin`；原生 DLL 来自包内 `.forge/cache/rxdll`。Node 本次没有动态加载 VC DLL，系统 `ucrtbase.dll` 来自 Windows System32；其余 7 个 VC 文件随包提供但本场景未加载，不声称 10 个全部已使用。

该冷启动同时确认最终 Web 入口，并成功渲染一帧 NVIDIA 1280×720 RGBA，无 fallback、截断或启动错误。模块路径清单、原生 PNG 与日志已留档；仅关闭自建进程，隔离目录已清理，既有用户桥未触碰。此检查没有重复两模式全程战斗。
