# 编译防线 V4 · 算力边疆

V4 将固定基地塔防改为地图上的实时经营与防御：电站生产电力，数据中心安装显卡生产算力，线路和移动基站支撑固定炮台及移动 AI。地图建筑、移动、寻路、资源消耗、科技与伤害由原生 Rust 核心负责，浏览器展示原生帧并下达指令。

本轮按用户要求进行制作、编译和打包，没有追加测试或自动试玩。V3 的历史验收不代表 V4 已经试玩验收。V1、V2、V3 独立包及旧运行实例保留。

## 启动

解压 `dist/CodeSentinels-V4-Windows.zip` 后双击 `Start-Game.cmd`。无需安装 Node、Python、Rust、RurixForge，不需要账号、API 密钥或编译器。

`Start-Game-GPU-Particles.cmd` 在同一游戏上额外开启实验 GPU 粒子。两种入口均保留原有真实图生视频制作的角色和技能帧动画。

`Start-PVP-Lobby.cmd` 为独立的局域网对战准备室入口，运行后把启动窗口中的服务器地址交给同一网络的朋友。双方打开同一个地址再通过房间代码加入。多人战斗同步尚未接入；准备室与配套协议已实现，详见 [多人基础设施说明](v4/MULTIPLAYER.md)。

## 从地图建立生产链

开局有 2000 金币、0 算力、科技 0，只预置一座生命值 400 的指挥核心。建议先花 180 金币在矿脉建设采集器，矿脉提供 6 金币/秒，煤层提供 4 金币/秒，采集器不依赖外部电力。

1. 选择地形与资源：初期先建风电，陆地可建，高地产能增加 50%；科技提高后可建水电、煤电和核电。水电需要距水域 2 格内，煤电需要距煤层 3 格内，核电需要距水域 4 格内取得冷却条件。建筑卡和地图落点提示会显示实际条件。
2. 在可用地面建设数据中心，连接发电站与数据中心的电力线。电力不足会影响算力供给，单纯购买显卡无法绕开发电与供电条件。
3. 点击地图上的数据中心，打开该中心的 GPU 机架并安装显卡。七种显卡沿用真实厂商照片：RTX 5060、5070、5080、5090、RTX PRO 6000、A100、H200。解锁条件由研究科技控制。
4. 部署 VS Code、PyCharm 固定炮台，或招募 DeepSeek 娘、GPT 娘等移动 AI。通过有线接入或移动基站为其提供算力。
5. 建立资源采集与研究设施，积累金币、升级科技，逐步扩大电站与数据中心规模，再应对更强入侵。

电力、算力、金币是不同资源。GPU 产出算力，发电站产出电力，资源经营与消灭入侵者带来金币。卡片上的功率、造价、产量、携带容量和科技等级是游戏平衡数值，不是现实硬件测评。

科技 1 解锁 DeepSeek、水电、煤电、移动基站、RTX 5080 与 A100；科技 2 解锁 GPT、RTX 5090 与 RTX PRO 6000；科技 3 解锁核电与 H200。研究院自身需要电力与算力线，研究消耗金币和算力。

## 有线驻守与无线机动

有线连接适合固定防线，算力线接入的 AI 进入驻守状态；需要调动时先解除有线连接。VS Code 和 PyCharm 始终为固定炮台。

移动基站覆盖内的 AI 可以移动并补充随身算力。离开覆盖后继续消耗电池作战；储备耗尽时仍可移动撤回，但没有足够算力就无法普攻或施放技能。将基站随主力前移可以扩大行动范围，但必须维持其与供给网络的联系。

移动基站基础回传范围为距可供能数据中心 14 格，无线覆盖半径为 6 格。点击基站可查看当前接入状态并下达移动命令。

选中移动 AI 后使用移动指令或右键指定目的地。可以拖框、追加选择和下达编队指令；地图支持缩放、平移、小地图定位。选中现有设施才能安装显卡、升级、回收或研究，减少卡片与地图之间的往返。

常用键：`B/U/I` 建筑/单位/显卡牌组，`1–9` 选卡，`L/C` 电力线/算力线，`W` 拖墙，`F` 切换闭合区充盾，`A` 移动，`Q` 技能，`E/R` 升级/回收，`Enter` 向选中数据中心安装显卡，`N` 下一波，空格暂停，`G` 覆盖层，方向键平移，滚轮缩放，`Home` 全图，`H` 手册。

## cudad 护城河与闭合防护

城墙以用户指定名称 **cudad 护城河** 出现。玩家花费金币在地图上绘制连续墙段，墙体改变通行与敌人接近建筑的路线。

护盾计算使用原生地图拓扑：从地图边缘向内部搜索未封闭的区域，真正被墙体围住的区域才具备封闭条件。区域内需要有效算力供给，玩家可投入算力充能形成保护。开口、墙体破坏及 Boss 对地形的重写会改变区域判定，不能仅凭轮廓看似环形就获得防护。

## 地图与敌人

地图扩为 32 × 20，保留三种战区主题并加入发电、矿产与建设地形。资源点和适合发电的地形引导扩张，线路把后方经营与前线作战连在一起。

敌人沿用真实软件 Bug 类型和既有完整美术。它们会对建筑与供给网络造成威胁；Boss 阶段变化和死亡继续改变部分真实地形并重新计算通路。保护经济设施、预留补给线路与及时调动 AI 都会影响战斗。

## 美术与来源

新增电站、数据中心、研究院、移动基站、资源设施、指挥核心和城墙的工业 RTS 建筑美术。提示词与源文件保存在 `Content/UI/v4`，发布图片在 `packages/client/public/games/code-sentinels/ui-v4`。

角色卡继续使用已核实的 DeepSeek 鲸鱼娘与 GPT 白龙娘形象，沿用已有真实图生视频角色动作与技能帧，不以新生成的虚构人物替代。真实硬件型号与照片的来源见 `references/sources-gpu.md`；人物来源见 `references/sources.md`，V3 卡面与来源链继续保留。

## 开发边界

新场景为 `Content/Scenes/Command.rxscene`，新原生核心为 `Content/Scripts/sentinels_v4.rs`，客户端入口为 `CodeSentinelsCommand`。旧 `Main.rxscene` 和 `sentinels_v2.rs` 保留；开发入口可用 `version=3` 回到旧界面。

客户端不模拟第二份经济或战斗，也不会重放断线期间的购买。正在进行的战场由当前引擎进程持有；不要把刷新、重新启动引擎或准备室恢复席位理解为完整战场存档。

多人原生实体预留 owner 归属；房间服务已提供玩家身份、阵营席位、准备状态、短时重连、连续指令序号、回执日志与服务器权威适配边界。当前单人战场不冒充双玩家对局。
