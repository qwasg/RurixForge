# V3 最终美术素材清单

已核对 **30 件实际素材：14 PNG + 16 SVG**，总计 30.94 MiB。每件文件都能解析，PNG 已完整解码；发布目录与 Content/UI/v3 备份逐字节一致。

PNG 包含4张角色卡面、3张硬件照片背板、3张战区插画、2张结算背景、1张标题背景和1张四技能图集。SVG 包含卡框、菱形技能框、部署/选中标记、纹样、图章、资源徽记与4类职业图形。skill-diamond-frame 的中央填充不透明度已核实为0，两处副本一致。

文件名、用途、尺寸、字节数与 SHA-256 均记录在 [artwork-inventory.json](artwork-inventory.json)。14张栅格图全部对应 [内置 imagegen 提示集](../../Content/UI/v3/art-prompts.json) 的唯一 key；提示集的整体哈希与每条提示词哈希也已记录。

预览联系图、官方参考截图和元数据文件均未计入30件交付素材；技能图集按一张实际文件计数。既有角色动作视频帧、原生战场资源和7张真实GPU照片属于复用资源，也未混入新美术计数。

本游戏采用原创工业战术风格。DeepSeek/GPT沿用已核实网络形象；硬件卡面将原创背板与真实厂商照片分层，显存事实与游戏平衡数值保持区分。来源见 [角色来源](../../references/sources.json)、[GPU来源](../../references/sources-gpu.json) 及 [界面参考说明](../../references/ui-v3-reference.md)。

本清单仅确认源素材完整性。最终包与实际卡牌视觉/交互验收由主任务确认，尚未在本清单中标记通过。
