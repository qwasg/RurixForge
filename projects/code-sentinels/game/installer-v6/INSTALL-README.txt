编译防线 V6 · 试玩安装包

安装完成后双击桌面“编译防线 V6 试玩版”，在打开的浏览器页面点击“开始人机攻防”。
所有游戏素材、Node、原生引擎和 VC 运行库均随包安装，不需要 Codex、Python、编译器或生成服务账户。试玩不会调用付费图像/视频生成服务。

运行要求
Windows 10 2004 或更新版本 / Windows 11，Intel 或 AMD 64 位处理器；CPU 需要 AVX2、F16C 等当前构建使用的指令集。显卡及驱动需支持 Vulkan 1.3 和 synchronization2；只支持 DirectX 并不足够。需要系统默认浏览器，建议保留至少 3 GB 可用空间。
当前试玩版本已在开发者的 Windows 11 / RTX 5060 Laptop 电脑运行；其他硬件和系统尚未逐项验证。

安装、存档与退出
默认仅为当前用户安装，不请求管理员权限。游戏的存档在安装目录的 .forge/save/v6，录像在 .forge/replays/v6，日志在 Logs/v6。
关闭浏览器页面不会自动结束正在运行的对局；切回名为“Code Sentinels V6 Preview”的最小化运行窗口，按 Ctrl+C 退出本地游戏服务。重新双击桌面快捷方式会优先打开同一安装目录的现有服务。
安装新版本或卸载前，请先保存并退出游戏。卸载会移除安装的程序和快捷方式，保留游玩后生成的存档、录像及日志；需要完整清除时，请在备份后自行移除剩余游戏目录。

对局提示
先建立毛坯、通道和房间，再选择房间用途。风电需要电力线接通数据中心；装入显卡才能产生算力。保护运输，争夺矿点与战略节点。单机、人机、局域网及直连入口均在大厅。
联机双方需使用同一版本。游戏不会自动配置防火墙或路由器端口转发。

版本状态
这是 V6 试玩候选的安装包装，完整游戏最终验收仍未完成。安装程序和游戏尚未取得代码签名许可，某些电脑的应用控制或信誉策略可能阻止启动；本安装包不修改或绕过这些保护。
角色形象、产品照片与生成素材的来源说明保留在 Sources 和 QA。部分素材的公开发行授权仍待解决，本安装包不为这些第三方素材新增许可。
