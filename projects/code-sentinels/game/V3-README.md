## 快捷键与卡牌操作

下列按键对照当前 `packages/client/src/lib/useTacticalHotkeys.ts` 的 `TACTICAL_HOTKEYS` 元数据：

- `1–4`：角色牌组选卡；`1–7`：显卡牌组选卡。`B` 切换牌组，`V` 收起或展开整副手牌。
- `Enter`：在显卡牌组将所选显卡接入首个空槽，需要足够建设经费。
- `Q`：为已部署守护者选择技能落点，再点击战场施放。`Esc` 可取消瞄准或部署。
- `E` 升级、`R` 回收选中对象；需先选中已部署单位或已安装显卡。`T` 切换所选守护者的目标策略。
- `Z` / `X`：上一个 / 下一个已部署守护者。
- `N`：开始下一波；`Space`：暂停或继续。
- `H`：帮助；`G`：辅助网格；`M`：音效。
- `Esc`：依次取消当前操作、关闭详情或收起手牌；弹窗中关闭弹窗。

也可直接拖拽角色卡到可部署地形，或将显卡拖到基地。翻面图标只查看卡背资料，不会部署。`Tab` 保留键盘焦点导航；焦点在按钮或链接上时，`Enter` / `Space` 激活该控件，不额外执行快速安装或暂停。

## 重连与存档契约

当前共享帧流客户端按0.5/1/2/5秒退避重连。同一引擎进程存活时保留当前战斗状态；连接断开本身不会暂停原生战斗。断线购买或施法不缓存、不补发，发送失败必须由UI提示重新操作。

存档仅保存战役解锁1–3，不保存本局GPU、单位、经费或波次。便携版使用 `.forge/save/code-sentinels-v2.txt`，V3沿用该格式。冷启动和完整重开会建立第1关新局并读取已解锁战区；新的V3包不自动复制用户V1/V2存档，也不带测试存档。
