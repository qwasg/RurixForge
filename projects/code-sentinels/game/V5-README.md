# 编译防线 V5 · 动态战线

V5 为 10 类经营建筑及 VS Code、PyCharm 两座固定炮台加入完整的落地、工作、摧毁视频帧动画，并补充 8 类命中与支援特效。原来的经营、供电、算力、科技、移动 AI 和城墙拓扑玩法保留。

## 启动与操作

完整解压独立包后运行 `Start-Game.cmd`，在打开的大厅中选择战区并点击“开始单人行动”。已有行动时可“继续当前行动”，或“重新部署此战区”。`Start-Game-GPU-Particles.cmd` 额外开启实验 GPU 粒子，两种入口均包含真实视频帧动画。游玩不调用付费生成服务，也无需安装开发工具或配置 API。

大厅提供战区选择、单人行动、联机准备室和显示/声音设置。资源界面展示当前经费、发电与用电、算力产能和容量、显卡机架以及研究状态；这些数值来自原生快照。战役解锁读取原生存档，不用浏览器缓存制造进度。

`H` 查看手册；`B/U/I` 建筑/单位/显卡牌组；`L/C` 电力线/算力线；`W` 建墙；右键或 `A` 移动；`Q` 技能；`E/R` 升级/回收；`N` 开始入侵；空格暂停。

`Start-PVP-Lobby.cmd` 仍提供局域网准备室。双玩家战斗同步尚未接入，详见包内 `MULTIPLAYER.md`。

## 动画与反馈

- 落地使用 32 个真实源帧，以 16 fps 播放一次。素材画幅、建筑中心和占地保持一致。
- 工作使用 48 帧、16 fps 循环。发电、采集、数据中心、移动基站与研究院依据原生工作状态播放；软件炮台仅在成功攻击后维持工作窗口，连续射击不会反复重置到片头。
- 摧毁使用 48 帧、24 fps，再保留真实末帧残骸 2.5 秒。即使游戏实体已被移除或其槽位再次使用，已有摧毁尾段仍独立播放。
- 命中反馈区分机械火花、算力脉冲、重击尘浪、护盾涟漪、断线电弧、维修、升级与坍塌爆炸。城墙动画由原生拓扑与事件时钟驱动，暂停/断线不自行推进。
- 核心失守后只继续视觉尾段，经济与战斗停止；战报遮罩等待摧毁过程结束，避免遮住核心爆炸。

## 素材与渲染

本轮已完成 44 个真实源视频：12 类建筑/炮台各含落地、工作、摧毁，共 36 段，加上 8 段特效。它们形成 20 个 RGBA 图集。每类建筑使用独立的 128 帧图集，单帧 256×256，统一补零帧名与固定锚点；8 类特效合计 320 帧，完整新素材共 1856 帧。清单与来源回执见 [媒体清单](v5/media-inventory.json)。

动作像素来自真实图生视频，源视频与每次生成回执保存在制作项目中。背景抠像、等时采样、固定画幅裁切和边缘透明处理是导入步骤，不以程序抖动或重复静图替代缺失动作。

渲染器通过 `spriteVariants` 和 `variantStride` 在预载图集间选择真实帧，不为每个动画类型创建大量隐藏精灵，也不随动画状态改变纹理注册顺序。数据中心屋顶不再叠放遮挡工作动画的显卡照片，真实型号照片继续保留在机架详情及资料卡中。

旧 DeepSeek/GPT 网络人物形象及原有真实技能视频帧继续使用。新机械炮台依据既有官方软件图标制作。素材提示词与来源见包内 `Sources`。

## 实测与当前验收范围

- 前端全量测试：67 个文件、735 项通过；后续 UI 修复的最终 3 文件、32 项定向补测及 TypeScript 检查也通过，两轮不累计为不同用例总数。
- 原生 CPU：6 组真实 DLL 场景通过，保留 42 条检查与数值记录，包含经营、供电研究、驻守线、真实受击/阵亡、完整尾段、槽位复用和三关十二波。
- 独立候选包：自带 Node 与原生引擎、禁用编译器，在 NVIDIA GeForce RTX 5060 Laptop GPU 上以 1280×720 运行。普通模式实测 54.75 FPS，粒子模式 54.72 FPS，均通过 30 FPS 阈值；每轮 16 项检查、7 张真实 RGBA 截图，无渲染降级、截断或原生运行错误。
- 局域网准备室已验证建房、加入、席位、准备与重连边界；`combatAvailable` 明确为 `false`，双玩家 PVP 战斗尚未接入。
- 真实浏览器操作检查通过：大厅进入/继续、资源定位、快建后正确布线一次、科技锁提示、实际 `Q` 技能命中并扣除 55 算力，以及房间准备流程均已验证。最终入口 `index-u-AInC4p.js` 的 144 个 Web 文件另通过内容一致与 HTTP 检查。
- 包内运行库冷启动通过：实际引擎使用 `bin` 内的 VC 运行库，原生模块从包内缓存加载，并完成一帧 NVIDIA 实渲。不同电脑的兼容性仍以实际硬件环境为准。

详细配置、证据路径和范围见 [V5 QA](v5/QA.md)。
