# 编译防线 V6

完整解压后运行 `Start-Game.cmd`。游戏使用包内 Node 和 Rurix 原生引擎；无需安装 Codex、开发环境或编译器。图像、模型和视频截帧随包提供，游玩不调用生成服务。

单人行动面对使用真实资源的经营型对手。多人选择建立房间，将 IP、游戏端口和六位房间码交给另一位玩家。对方运行相同版本的完整游戏包后选择“加入”，填写 `IPv4:端口` 或 `[IPv6]:端口` 及房间码，双方准备，由房主开始。双方各自在本机原生渲染，摄像机与楼层独立。

公网直连需要房主自行配置可达的游戏端口及所需 NAT／防火墙转发；游戏不会自动修改这些设置。只转发游戏端口，编辑器、文件和本机画面服务不随之开放。准备室中离线超过60秒的客席会释放，可以凭正确房间码重新加入。

房主程序需保持运行。连接中断保留席位 60 秒，期间战斗继续；超时由原生权威判负。局域网端口仅提供游戏协议，编辑器、文件、场景和画面服务不向其他电脑开放。

先规划毛坯与通道，再划分房间并指定功能。风力发电需要电力线接入数据中心；装入显卡后才产生算力。研究室及固定炮塔需要相应网络。移动 AI 在无线覆盖外消耗随身算力。矿石、弹药与维修物资需要真实运输。

每个研究所选择一个科技方向，多所可以发展不同分支；高级研究争夺科研数据并持续投入资源。保护核心，同时争夺地图资源和战略节点。第 18 分钟开放战略压制，持续占多数节点可获胜；争夺或失去多数会打断或回退进度。

运输载具可设置最多 16 个航点，每次改线消耗 2 金币；清空航点可恢复自动路线。载具会走完当前路段再转向，障碍不会让货物瞬移。到达后仍须卸货，基础速度每秒40单位；装卸加成缩短时间，不增加货量。空运仅在己方供电的地面机场跑道之间进行：派遣消耗 80 金币并从起点实装燃油，起降各需 2 秒。矿石运到机场只入库存，继续由地面运输送到核心或仓库才结算金币。运输机受攻击会损失货物与燃油，目的机场失效时会尝试在油量和容量允许的机场降落。

界面提供保存、读取和回放。读取未结束的联机存档会先建立新准备室，双方准备后继续原战局。录像可暂停、调整速度和跳转时间。V6 存档在 `.forge/save/v6`，对战指令日志在 `.forge/replays/v6`；V5 存档不迁移或覆盖。日志在 `Logs/v6`。关闭游戏程序结束本机引擎。

本说明描述 V6 设计与接口。打开包内 `v6-candidate.json` 查看交付状态：`candidate: true` 是体验候选，未宣告完整验收；`candidate: false` 才表示独立发布证据已逐项核验。正式包同时包含 `QA/acceptance.json`、`QA/release-verification.json` 及 `QA/evidence-index.json`。索引将原始回执路径对应到包内的实际证据文件，并说明不随包分发的开发日志。不能用一个 `passed` 字段替代完整验收。

人物来源与五张原始社区设计参考保存在 `Sources/references/v6`，它们是有作者和版本记录的社区形象，并非各公司统一官方拟人设定。`QA/media` 保存真实视频抽帧、像素密度与原生渲染生命周期核验；报告明确记录实际测试的引擎哈希和视觉测试范围。资源、素材清单和每个打包文件的 SHA256 均记录在交付清单中。

开发时使用 `python game/build_portable_v6.py --web game/v6/web-complete-media-20260911 --no-zip` 组装独立候选；从项目根目录执行，Python 需支持 `hashlib.file_digest`。显式 `--engine`、`--build-receipt` 可指定匹配的原生引擎及编译回执。已有目录只有在带有 V6 候选标记且传入 `--refresh-candidate` 时才可更新；此前管理文件会整体存入同级 `.v6-candidate-history`，本地 `.forge`、`Logs` 及未识别的用户文件保留。也可用 `--out` 指向新父目录内的 `CodeSentinels-V6-Windows`。V5、旧 ZIP 和已发布目录不会被覆盖。

移除 `--no-zip` 只在最终证据完成后使用，必须提供符合 `Sources/RELEASE-ACCEPTANCE-SCHEMA.md` 的 `--acceptance` 文件。发布门槛分别检查普通付费功能流程、完整 1,000 场分支与 126 场策略实验、匹配引擎与规则的满载性能、至少 45 分钟双原生本机渲染联机，以及隔离目录冷启动。最终 ZIP 按完整白名单写入，再核对 CRC、逐文件哈希和状态标记；未完成或版本不符的测试会阻止发布，不影响保存体验候选。
