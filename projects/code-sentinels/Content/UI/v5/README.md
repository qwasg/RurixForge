# V5 图生视频参考图

本目录保存由 Codex 内置 `image_gen` 逐件制作的 10 张静态参考图：8 类特效的初始火种与 2 座完整机械炮台。这里的图片是实际图生视频的输入，不是动画序列或伪造的帧图集。

`vfx-references/` 中的特效采用固定俯视镜头与中心小起始形态，为视频中的扩张和消散留出边界。机械命中、算力脉冲、护盾接触、断线电弧、维修、科技升级为纯黑底；重击尘浪采用洋红近色底。建筑毁灭爆发由内置工具返回透明 RGBA，视频准备阶段将其铺到纯洋红，以便后续抠像保留暗烟与碎片。

`building-references/` 中的 VS Code 精准单管炮台与 PyCharm 矩阵四管炮台使用项目已有官方软件标识作为输入参考，嵌在底座装甲牌上。完整炮台为透明 RGBA。生成源图的边距并非统一，媒体准备流程按透明轮廓裁边、统一占画面 64%，提供 18% 的动作安全边界，然后用于真实建成、运转、毁坏三态视频。

每张最终参考图同时保存到 `packages/client/public/games/code-sentinels/ui-v5/` 对应目录。`reference-manifest.json` 是文件清单；`vfx-reference-prompts.json` 与 `building-reference-prompts.json` 记录提示词、实际输出来源及内置编辑步骤。所有最终图为 1254 × 1254。

已有 AI 人物、V4 建筑与 V2/V3 视频原件未在此次参考图制作中修改。实际视频提交、回执、后处理和动画图集由独立媒体流程保存。
