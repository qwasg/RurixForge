# V4 建筑美术

本目录保存通过 Codex 内置 `image_gen` 逐件生成的原创静态建筑素材。建筑采用象牙白、炭黑、琥珀和青色的工业 RTS 视觉；用于原生地图实体和网页卡面。不是对红警原作素材的复制。

正式素材共 10 件，均为 RGBA PNG。9 件建筑原图为 1254 × 1254，墙体横向模块为 2172 × 724。文件清单和卡面引用见 `art-manifest.json`。水电和核电的正式稿是最终重新生成的紧凑方形建筑，不采用早期带背景的候选图。

`art-prompts.json` 记录每件最终提示词、内置工具输出路径、项目路径与网页引用。图片原样保留生成的透明通道，网页副本位于 `packages/client/public/games/code-sentinels/ui-v4/art/`。原生 sprite/图集由场景构建导入，不把静态建筑图声明为视频或动画。

建筑包括数据中心、四类发电站、移动基站、研究院、cudad 护城河、指挥基地和资源采集站。`cudad-wall.png` 为横向模块插画，连接关系、闭合区域及护盾填充由玩法拓扑处理。移动基站采用完整通信车造型。

已有真实来源的 AI 人物、GPU 照片和图生视频帧动画保留原件。此次美术制作未重新提交付费视频生成。
