## 选用 GPT 龙娘（特定 YouTube 展示版本）

本地干净参考：[白紫龙娘原图](gpt-dragon-jpethan.png)。浏览器实拍证据：[视频约 0:37 参考画面](gpt-dragon-youtube-037.png)。

实际打开、播放并查看了 [YouTube 视频](https://www.youtube.com/watch?v=xASRX37IIiY)《DeepSeek 有的，我们 GPT 也要有！桌面 Token 龙娘来了｜macOS 主力开发、Windows 测试中》，上传者 **ゆうまEthan〜**，页面日期 **2026-08-28**。展开简介提到 token-monitor 项目和 B 站 BV1Ro866nEVh。

随后找到 [JPEthan/token-monitor](https://github.com/JPEthan/token-monitor)，下载并查看 Resources/Mascot/dragon-chibi-neutral-v4.png，外观与实际视频一致。可直接观察：白长发、紫眼、双白角、尖耳、左右浅紫龙翼、白紫高领露肩衣与宽袖、紫色菱形胸饰与单侧垂挂紫晶。**原图到腰部为止；腿部和尾巴尚无视觉证据。** 游戏采用半身召唤投影，底下可配软件设施底座，不凭空加角色身体。

项目作者表示此图使用 GPT 图像生成，但确切生成模型、提示词和参考输入来源未完整记录。其 [素材许可](https://github.com/JPEthan/token-monitor/blob/main/ASSET_LICENSE.md) 明确排除 MIT，未向其他产品另授抽出、修改或再分发权。原始图仅作为研究参考，不直接打包到游戏发行物。相关原文已保存在 gpt-dragon-ASSET_LICENSE.md、gpt-dragon-ASSET_RIGHTS.md。

没有查到可以核实的统一 VS Code娘 / PyCharm娘，按主任务决定采用真实软件标识与工具设施。

- **Rust**：[software/rust.svg](software/rust.svg)。来自 [rust-lang/rust-artwork](https://github.com/rust-lang/rust-artwork) 的 logo/rust-logo.svg；按 [Rust Logo 与媒体指南](https://foundation.rust-lang.org/policies/logo-policy-and-media-guide/) 标记品牌来源。
