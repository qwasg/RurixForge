## 核实边界

RTX 5070 虽来自 family 页面，但选定图片的文件名和实际卡身标识均为 5070，未使用标为 5070 Ti 的 OpenGraph 图。PRO 6000 明确为 Blackwell Workstation Edition。A100 明确选 80GB PCIe；H200 明确选 NVL PCIe（每卡141GB），未把SXM模块或整机照片混用。

产品图与商标权利归原厂；官网可下载不自动意味着通用再发布许可。GPU 原图用于本地同人游戏流程测试。机器可读来源及型号细节在 sources-gpu.json。
