# RurixForge 0.2.0 · 2026-11-02

本次发布同步 0.1.0 之后的桌面工作台、Agent、资产管线和运行后端改动。

- Build 模式增加项目调查、预览审阅、施工与场景一致性检查，预览和任务状态可以在工作台中查看。
- 新增 2D 绑骨核心、编辑器、时间线和动画相关工具，并接入场景与 Godot 运行时。
- 完善角色模型导入、自动绑骨、动画和资产发布流程，补充 Blender、Meshy 接入说明与工具。
- 增加自定义模型渠道与 Anthropic 兼容调用，更新模型切换、对话活动、任务与协作状态展示。
- 更新原生视口、实时渲染适配、共享纹理生命周期与退出清理；安装程序增加启动小窗及新的安装界面。

Windows 安装包仍包含本地后台服务、Godot 运行时和 UltraPlan 浏览器验证运行时。模型与素材生成服务需要自行配置。安装包暂未签名，下载时可使用同一 Release 附带的 `SHA256SUMS.txt` 核对文件。

源码构建需要 Rust 1.94 或更新版本。原有 Git 锚定的 Rurix 物理依赖继续保留；桌面端新增的实时渲染接口依赖冻结在 `vendor/rurix-20261102/`，Naga 修复冻结在 `vendor/naga-25.0.1/`，避免其他机器依赖本机的 `D:/Rurix` 覆盖。冻结目录的 `SNAPSHOT.json` 记录来源、文件哈希和清单适配；它包含上游尚未提交的库改动。

本版本仍是开发中的工作台。实验性渲染画质、性能与自动生成内容需要分别实测验收；本次发布不表示独立渲染项目的实验门槛已经通过。本机用户数据、账号配置、原始生成记录与测试截图不随源码同步。
