Install

Ready in three stepsReady in three steps

  1. i

    1. Download and verify

    Grab RurixForge-Setup-0.2.0.exe (539.5 MB), open PowerShell in its folder and check the SHA-256 with this line:

    PS> Get-FileHash .\RurixForge-Setup-0.2.0.exe -Algorithm SHA256
  2. ii

    2. Get past SmartScreen

    The installer isn’t code-signed yet, so Windows may say “Windows protected your PC”: click More info, then Run anyway.

  3. iii

    3. Install, connect a model

    Click 立即安装 (Install now) — no administrator rights needed. Then connect a model in Settings and describe the game you want to make.

Optional: Edge or Chrome (UltraPlan’s web demos; Windows ships with Edge), ffmpeg, Blender, Codex.

Where your data lives

  • App%LOCALAPPDATA%\Programs\RurixForge
  • Sessions, settings, projects%APPDATA%\RurixForge\data
  • Logs%APPDATA%\RurixForge\logs

Uninstalls and upgrades keep %APPDATA%\RurixForge; to remove everything, delete it after uninstalling.

From source

Build from sourceBuild from source

Want to change the code, or try the latest development build? Run these lines in PowerShell. The script checks for Git, Node.js, Rust and the C++ build tools and installs anything missing through winget (asking first).

RepositoryInstall & packaging guide

# Get the source

PS> git clone https://github.com/qwasg/RurixForge.git
PS> cd RurixForge

# Set up the dev environment

PS> powershell -ExecutionPolicy Bypass -File scripts\setup.ps1

# Launch the desktop app

PS> pnpm dev:desktop
