# Dependency notices and rights inventories

These are review materials for the proposed source publication. They preserve upstream declarations and do not establish that every dependency is linked into the final executable, that all redistribution obligations are complete, or that omitted media has been cleared.

- [Dependency license inventory](dependency-license-inventory.json): 161 resolved Cargo graph packages and links to the retained license texts in `licenses/dependencies/`.
- [Asset-rights ledger](asset-rights-ledger.json): ten excluded-media groups and remaining permission/replacement decisions; no private contact material.
- [Review scope and remaining rights work](../docs/third-party-and-asset-rights.md).

- [Rurix MIT](licenses/Rurix-MIT.txt) and [Rurix Apache-2.0](licenses/Rurix-Apache-2.0.txt).

- [Inter OFL-1.1](licenses/Inter-OFL-1.1.txt) and [JetBrains Mono OFL-1.1](licenses/JetBrains-Mono-OFL-1.1.txt).

These notice copies do not include the corresponding fonts, runtime binaries or game artwork. Upstream copyright/contact text in original licenses remains upstream attribution, not an application contact or a new project maintainer assignment. The final distribution must retain every notice actually required for its selected components, including any additional nested native-library obligations.

For non-sensitive corrections, use [GitHub issues](https://github.com/qwasg/RurixForge/issues). The proposed accountable maintainer is [qwasg](https://github.com/qwasg), pending review of the public policies and roles.
